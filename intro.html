RED LAN-Packet Tracer

Este es un proyecto individual donde el reto es diseñar una red local completa para una casa de tres niveles. Para esto, voy a utilizar el simulador Cisco Packet Tracer, que me permite montar toda la infraestructura de forma virtual, configurar los equipos y probar que la comunicación funcione perfectamente antes de pensar en algo físico. Debo demostrar que sé configurar seguridad, IPs Clase B y cómo hacer que el internet llegue a todos lados mediante una conexión en cascada.

Mantenimiento de computadoras

Este es nuestro primer parcial práctico. Se trata de realizar un mantenimiento preventivo completo a una computadora real. No es solo desarmar y limpiar, sino que tenemos que documentar todo el proceso, investigar los componentes internos y presentar un informe profesional que demuestre que sabemos cómo cuidar y diagnosticar el equipo.

Instalación de Ubuntu

Esta es una tarea formal e individual donde tengo que demostrar que puedo instalar y configurar el sistema operativo Ubuntu Linux desde cero. El objetivo es aprender a usar máquinas virtuales con VirtualBox y empezar a manejar la terminal de Linux, que es fundamental para nuestra carrera de Ingeniería en Sistemas.

Cables de Red

En esta práctica vamos a ensuciarnos las manos con el hardware de red. El objetivo es fabricar dos cables de 3 metros: uno Directo (para conectar compus a un switch) y uno Cruzado (para conectar dos compus entre sí). No es solo de juntar cables, tenemos que seguir normas internacionales (T568A y T568B) y usar herramientas profesionales para que la conexión sea perfecta.

Configuración de una RED LAN

En esta práctica vamos a pasar de lo físico a lo lógico. El objetivo es interconectar tres computadoras usando el Switch y los cables que fabricamos antes. Tenemos que lograr que las máquinas se "hablen" entre sí mediante direcciones IP estáticas y, al final, demostrar que podemos transferir archivos de una compu a otra sin necesidad de internet o memorias USB.

Base de datos

Este proyecto consiste en analizar tres casos del mundo real (una Biblioteca, una Tienda y una Red Social) para convertirlos en bases de datos funcionales. El reto es pasar desde el dibujo lógico de las relaciones hasta la implementación física en el servidor, asegurándonos de que los datos estén bien estructurados y relacionados.
